# Beş Kural Asistanı

Öğretmenin yapay zekâ ile içerik üretirken beş kuralı sırayla uygulamasına yardım eden tek sayfalık araç.

Sayfa hiçbir yapay zekâ hizmetine kendisi bağlanmaz: her adımda isteği verir, siz kendi sohbetinize (Claude, ChatGPT, Gemini) yapıştırır, cevabı sayfaya geri yapıştırırsınız. Hesap gerekmez, veri sayfadan dışarı çıkmaz.

Gazi Üniversitesi Eğitim Teknolojisi YL, Öğretmen ve Teknoloji dersi sunumu için hazırlanmıştır (26 Kasım 2026).
